Konfigurasi API Key & Place ID Studio Lite

API Key Anda dienkripsi dengan AES-256-GCM di server dan tidak pernah ditampilkan kembali.

Langkah-Langkah Membuat API Key & Setup Studio Lite (Tanpa Verifikasi KTP)

Langkah 1: Siapkan 1 Place Uncopylock di Akun Roblox Anda
1. Buka Roblox Creator Hub - Creations.
2. Klik titik tiga pada salah satu Experience/Place kosong Anda → pilih Copy Universe ID dan klik masuk untuk menyalin Place ID.
3. Masuk ke menu Configure Place → Permissions, lalu centang "Allow users to download a copy of this place" (Uncopylock) dan klik Save.
Langkah 2: Buat Open Cloud API Key
1. Buka Creator Hub - Credentials lalu klik Create API Key.
2. Pada bagian Access Permissions, tambahkan:
• universe-places (Experience Management): pilih Experience Anda dan centang write.
• Assets API: centang read & write.
• Creator Store Products: centang read & write.
3. Pada bagian Accepted IP Addresses, isi 0.0.0.0/0 lalu klik Save & Generate Key.
4. Salin API Key tersebut dan simpan pada form di atas.
Langkah 3: Cara Memasukkan ID ke Map Studio Lite
1. Buka game Studio Lite di Roblox.
2. Buka Toolbox → Import Model.
3. Masukkan ID yang keluar dari web ini, lalu tekan Get / Import. Seluruh isi map (Workspace, StarterGui, dll.) akan langsung masuk ke Studio Lite!
